VILLAWOLF · ADMINISTRACIÓN

Administra tu modpack

Prepara los cambios de CurseForge y publícalos para tus jugadores.

1. Selecciona y analiza

Selecciona tu instancia de CurseForge para empezar.

Historial y recuperación

Recuperar prepara una versión nueva con los archivos anteriores. La publicación actual sigue activa hasta que confirmes otra.

2. Revisa la actualización

Mods

Protección de datos

Se excluyen mundos, cuentas, logs, opciones del jugador y credenciales. Revisa los archivos seleccionados antes de publicarlos.

Nombre, fondo y novedades

El nombre conserva la identidad de la instancia y sus mundos. El fondo se aplica al inicio y a las tarjetas; fondo y notas requieren VillaWolf Launcher 0.1.11. Se verifica esa versión antes de activar la publicación.

Configuraciones, shaders y recursos

Los archivos ya administrados vienen seleccionados. Marca los nuevos que deseas distribuir. Los archivos desmarcados dejan de administrarse; el launcher conserva las modificaciones personales.

3. Publica cuando esté probado

Primero prueba esta versión desde CurseForge. No necesitas crear una Release del launcher.

Conectar mi GitHub para publicar

Crea un token de acceso fino para este repositorio con Contents → Read and write. Pégalo aquí; no se guarda en archivos ni se envía al chat. No necesita permisos de administración ni de workflows.

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
